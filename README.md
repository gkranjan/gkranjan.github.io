## Publish using GitHub Pages
1. Back up your current repository: https://github.com/gkranjan/gkranjan.github.io
2. Extract this ZIP on your computer.
3. Upload the **contents** of the extracted `gkranjan-portfolio` folder to the repository root (not the outer folder).
4. Keep your existing photo at `assets/profile.jpg.png`. This ZIP intentionally does not include a fabricated portrait.
5. Commit the changes to `main`.
6. Open repository **Settings → Pages** and confirm deployment from `main` and `/` (root).
7. Visit https://gkranjan.github.io after deployment. Use `Ctrl + F5` if your browser shows a cached version.
