# Gautam Kumar Ranjan – Portfolio Website

A responsive personal portfolio website for a Java Backend Developer. Built with HTML, CSS, and vanilla JavaScript.

## Website
After publishing with GitHub Pages:
- https://gkranjan.github.io

## Files
- `index.html` – website content and sections
- `style.css` – responsive styling and layout
- `script.js` – mobile navigation and footer year
- `assets/` – profile image, resume PDF, and favicon

## Before publishing
1. Replace `assets/profile-placeholder.svg` with your own professional photo. Rename your photo to `profile.jpg` and update the image path in `index.html` from `assets/profile-placeholder.svg` to `assets/profile.jpg`.
2. Add your PDF resume as `assets/Gautam-Kumar-Ranjan-Resume.pdf`.
3. In `index.html`, replace each project link currently pointing to `https://github.com/gkranjan` with the exact repository URL for that project.
4. Review the skills and remove any technology you are not yet comfortable discussing.
5. Check your LinkedIn URL and contact details.

## Publish using GitHub Pages
1. Create a public repository named `gkranjan.github.io`.
2. Upload the contents of this folder to the repository root (upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder; do not upload only the outer folder).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to finish deploying, then visit https://gkranjan.github.io.

## Update the website
Edit the relevant files locally, then commit and push the changes to the `main` branch. GitHub Pages will redeploy automatically.
